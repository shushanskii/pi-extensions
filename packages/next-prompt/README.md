# next-prompt

A suggested next message, shown as grey ghost text in the empty editor.

```bash
pi install npm:@developer/next-prompt
pi remove npm:@developer/next-prompt
```

Config: `~/.pi/agent/next-prompt.json`, every key optional — the defaults are the working values. Shape: [`next-prompt.json.example`](./next-prompt.json.example).

The why — design, measurements, failure modes — is the header comment of [`index.ts`](./index.ts); it is kept there so that it travels with the code.
